# Memory Systems

## 1. RAM (Random Access Memory)

RAM holds data that the CPU needs to access quickly. It is **volatile**: when power is lost, its contents are lost.

- **DRAM (Dynamic Random Access Memory)** — a type of RAM that stores bits in cells that must be refreshed periodically.
- **SDRAM (Synchronous Dynamic Random Access Memory)** — a type of DRAM synchronized with the system's memory clock.
